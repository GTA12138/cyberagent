## 审查结论与范围

项目方向是 Go + PostgreSQL + norma 驱动的任务平台：全局资产图记录资产，探索图记录目标、意图和事实，planner/worker 通过事件推进；流量、证据、报告及会话/隧道作为独立模块接入。纸色主题与 YMH 界面迁移已经完成，本次没有推翻现有技术栈或界面。

源码目录未包含 Git 元数据。改动前的相关源码保存在 `.build/project-audit-20261023/baseline/`，不包含配置、凭据或业务数据。旧路线图、设计稿中的操作建议作为背景材料核实；没有把其中所有未来设想当作本次已实现功能。

本次完成的是录制/路由一致性、补全生命周期、证据版本与投影一致性、关键页面状态、隔离验证及可复现质量入口。**整个路线图尚未全部实现**。共享资源租约、任务终态资源释放、身份/认证结果账本、统一预算及实验/证据合同等仍为待办，不能用本次通过的回归代替这些交付。事项状态见同目录 `YMH-待办总表.md`。

## 已实现改动

1. **T-02：录制和任务路由解耦。** `Traffic.SetRecordEnabled` 只控制交换记录、正文、Blob 和索引持久化，不改变上游、路由钩子、CA 或连接。写锁确保关闭返回后不再有排队记录写入；已有历史保留。任务代理管理器将设置同时应用到存量和新建实例，启动前设置持久化状态；Manager 串行处理录制设置的保存与应用，任务代理与阻断状态不再由录制开关决定。
2. **提示词依据最终工具集。** worker 的流量说明使用显式布尔值，来自权限和绑定过滤后的 `traffic_search` + `traffic_get` 是否同时存在。CA 路径只表示 TLS 信任。核实源码后，planner/mainagent/chat 原本没有“按 CA 注入流量说明”的逻辑，因此没有机械修改它们的函数签名。
3. **补全任务隔离与退出顺序。** 资产和派生 URL 的冷却键纳入 taskID，防止一个任务的抓取抑制另一任务的端点回灌。补全引擎关闭时取消在途 HTTP 和语义分析并等待 worker；失败/取消的半份响应不作为材料继续派生。Manager 在关闭代理/索引和 PostgreSQL 前先关闭补全。DNS 仍使用现有解析器，关闭等待其已有超时，不作即时取消承诺。
4. **代理诊断脱敏。** 上游变更和错误日志不再直接输出含口令的代理地址；无效 URL 的解析错误不回显原始输入；诊断输出剥离查询参数和 fragment。
5. **验证入口。** `scripts/test.ps1` 每次创建独立 PostgreSQL 集群，只绑定 loopback，结束后停止；保留逐用例 JSON、通过/跳过计数、前端检查日志。`web/package.json` 增加 `test` 和 `typecheck`。普通分支和 PR 增加 Go 与前端质量检查，原 release 工作流保留。
6. **API 测试生命周期。** CRUD 测试不再用永久后台 context 启动恢复任务、调度和外部模型调用；需要执行的核心生命周期测试使用活 context 并在关闭存储前取消、等待任务循环。未删除测试断言，也没有把失败用例改成 skip。
7. **发现与验证完整性。** 合并后的新证据版本回到 pending；创建检查按证据版本去重并停用旧活跃检查；完成检查/复测时比较快照版本，旧结论仅留历史。检查保留人工非 pending 处置，复测同时校验快照处置状态，避免覆盖期间的新处置。已作废检查的自动首次派发不会重新进入执行。名称/分类/严重度与节点投影同事务提交，节点更新失败整笔回滚；证据版本和归档冻结检查统一。
8. **编辑与读取状态。** 工作空间按草稿 ID 和提交内容确认保存，保存期间新增输入保持 dirty，关闭有草稿确认并保护刷新。目录和文件响应有序号；任务、发现增加持续失败/旧快照提示及重试，资产视图按范围和分页拒绝旧响应，组内首次失败仍能重试。内网台账的响应按任务和请求序号隔离，切任务清除旧工作台和主机筛选，各指标在未知时显示破折号。
9. **复核发现的边界。** 任务代理开始关闭时先关闭该实例录制，再移出活跃集合，避免证据读取租约延迟关闭期间漏接录制开关。测试入口保存、清空并恢复真实模型 opt-in；评测逐项核验清单里的指定测试确实产生 pass，改名/缺失/skip 不能算通过。

| 模式 | 缺端点站点数 | 端点增量 | 流量交换记录 | 出口 |
| --- | --- | --- | --- | --- |
| 录制开启 | 1 → 0 | +2 | 2 | 指定任务代理及上游 |

本地单元及集成回归验证代码合同，不能证明远端协议、真实 Windows 目标、多网段拓扑或长期自主运行效果。E1 保持部分状态；没有设置真实站点验收完成，也没有接通 JS 语义模型或增加新的横向执行协议。

独立结论为：架构设计能力中上，双图、原子领取和独立证据仓有完整机制；工程成熟度中等，重点差距在跨机制合同、统一预算和资源存活管理；纸面视觉体系已成形，页面失败、草稿和作用域合同需要持续统一。没有以主代理自评代替独立结论，也没有将通过测试解释为自主安全测试效果已获证明。
